## 💡 搜索技巧

做项目遇到问题是常态，会搜索也是一项重要技能。分享几个我常用的搜索技巧：

1. **直接搜报错信息** - 把报错信息复制粘贴到搜索框里，最有效
2. **加关键词限定** - 比如搜 "STM32 MPU6050 I2C 卡死" 比 "MPU6050 不工作" 更精准
3. **英文搜索** - 有些问题中文资料少，试试英文关键词，Stack Overflow 上可能有答案
4. **GitHub 搜代码** - 不确定怎么实现的功能，去 GitHub 搜一下，看看别人是怎么写的
5. **B站搜教程** - 有些操作类的问题（比如软件怎么配置），看视频比看文字快
