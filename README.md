## 📋 项目简介

本项目基于 **STM32H743VIT6** 高性能微控制器（Cortex-M7 内核，480MHz），设计并实现了一套完整的多传感器融合智能车控制系统。

通过集成 MPU6050 六轴传感器、三路超声波、五路红外循迹、光电编码器等多种传感器，结合 **PID 控制算法** 与 **卡尔曼滤波**，实现了智能车的自主循迹行驶、障碍物规避、定速巡航、蓝牙遥控等功能。

项目采用模块化软件设计，代码结构清晰，便于调试和功能扩展。硬件部分使用 Altium Designer 设计 PCB，实现了一体化控制板。

> 💡 **做这个项目的初衷**：大二的时候上了嵌入式系统课程，觉得只学课本上的知识不够，想动手做一个完整的项目练手。一开始只想做个简单的循迹小车，后来越做越上头，陆续加了超声波避障、蓝牙遥控、卡尔曼滤波这些功能，就变成现在这个样子了。

## 📚 学习路径

这是我做这个项目的学习路线，从零基础到能做出一个完整的智能车，大概花了两个多月的时间。如果你也想做类似的项目，可以参考这个路径：

### 第一阶段：入门基础（GPIO + 定时器）
- **知识点**：STM32 基础、GPIO 输入输出、定时器基本原理
- **练习项目**：点亮 LED、按键扫描、蜂鸣器播放音乐、定时器中断闪烁 LED
- **预计时间**：1~2 周
- **踩坑提醒**：一开始一定要搞清楚时钟树！H7 的时钟比 F1 复杂多了，我刚开始的时候因为时钟配置不对，串口一直乱码，调了两天才发现是时钟频率设错了。

### 第二阶段：PWM + 电机控制
- **知识点**：PWM 原理、定时器 PWM 输出、电机驱动原理（L298N / TB6612）
- **练习项目**：用 PWM 控制 LED 亮度、驱动电机调速、小车前进后退转向
- **预计时间**：1 周
- **踩坑提醒**：TB6612 比 L298N 效率高很多，建议直接用 TB6612。另外电机电源和单片机电源一定要分开，不然电机启动瞬间的压降会导致单片机重启。

### 第三阶段：编码器 + 速度闭环
- **知识点**：编码器原理、定时器编码器模式、PID 控制算法基础
- **练习项目**：读取编码器转速、用 PID 实现电机定速、左右轮速度同步
- **预计时间**：1~2 周
- **踩坑提醒**：PID 参数调参真的是玄学，建议先从只有 P 开始调，然后加 I，最后加 D。可以用上位机把速度曲线打出来，比瞎调效率高多了。

### 第四阶段：传感器（超声波 + 红外 + MPU6050）
- **知识点**：超声波测距原理、红外循迹原理、I2C 通信、MPU6050 六轴数据读取
- **练习项目**：超声波测距、红外循迹检测、读取加速度计和陀螺仪数据
- **预计时间**：2 周
- **踩坑提醒**：MPU6050 的 I2C 地址一定要对！有的模块是 0x68，有的是 0x69，AD0 引脚接的不一样地址就不一样。还有陀螺仪一定要校准零偏，不然漂得很厉害。

### 第五阶段：PID 进阶 + 卡尔曼滤波
- **知识点**：位置式 PID vs 增量式 PID、积分分离、抗积分饱和、卡尔曼滤波原理
- **练习项目**：PID 转向控制、卡尔曼滤波融合加速度计和陀螺仪数据、姿态角解算
- **预计时间**：2~3 周
- **踩坑提醒**：卡尔曼滤波的 Q 和 R 参数真的很难调，建议先找别人调好的参数作为起点，然后慢慢微调。还有 dt 一定要准确，不然角度会飘。

### 第六阶段：传感器融合 + 综合功能
- **知识点**：多传感器数据融合、异常值检测、系统状态机设计
- **练习项目**：循迹+避障综合模式、蓝牙遥控、OLED 显示调试信息
- **预计时间**：2 周
- **踩坑提醒**：功能多了之后一定要做好任务调度，别所有东西都往 main 函数的 while 里塞。用时间片轮询或者 RTOS 会好很多。

> 更详细的学习路线图请参考 [docs/learning-path.md](docs/learning-path.md)

## ⚙️ 核心算法

### 1. PID 控制
- 实现了 **位置式** 和 **增量式** 两种 PID 算法
- 支持 **积分分离**，避免大偏差时积分饱和
- 支持 **输出限幅** 和 **积分限幅**
- 用于电机调速和转向控制

### 2. 卡尔曼滤波
- 二阶卡尔曼滤波，融合加速度计和陀螺仪数据
- 估计车体姿态角（Pitch / Roll）和陀螺仪零偏
- 有效抑制加速度计的高频噪声和陀螺仪的零漂
- 姿态更新频率 1kHz，角度输出稳定

### 3. 多传感器融合
- 三路超声波数据加权融合，提升测距可靠性
- 红外循迹五路信号综合判断，提高识别准确率
- 异常值检测与剔除（基于阈值和历史数据）

## 💡 学习心得

### 做这个项目最大的收获

说实话，这个项目比我预想的难多了。一开始以为不就是个小车吗，能有多难？真正做起来才发现，每一个小模块都有好多坑。

**印象最深的几个坑：**

1. **电机干扰问题** - 最开始电机和单片机共用一个电源，电机一启动单片机就死机或者复位。查了好久才发现是电机的反电动势干扰，后来加了电容、用了独立电源、又在电源线上加了磁环，才彻底解决。这个问题困扰了我整整一周。

2. **PID 调参的痛苦** - 一开始调 PID 的时候，完全是瞎调，参数改来改去，小车要么抖得像筛子，要么慢得像蜗牛。后来学长教我用串口把速度数据打出来，用 Excel 画曲线，才慢慢找到感觉。现在回头看，其实就是 P 太大了导致振荡，I 太大了导致超调，D 是用来抑制振荡的，但 D 太大又会放大噪声。

3. **卡尔曼滤波的数学** - 卡尔曼滤波的公式真的劝退，我看了好几天才勉强看懂。不过好在实际用的时候，不需要完全搞懂数学推导，知道怎么调 Q 和 R 参数就行。我是先抄了别人的代码跑起来，然后边调参数边理解原理，慢慢就懂了。

4. **I2C 总线的坑** - MPU6050 的 I2C 通信一开始经常卡死，后来发现是上拉电阻阻值不对，还有走线太长。换了 4.7K 的上拉电阻，把线剪短了就好了。硬件的坑真的是不踩过不知道。

### 给学弟学妹的建议

如果你也想做类似的项目，给你几个建议：

1. **别急着写代码** - 先把原理搞懂，至少知道这个模块是怎么工作的，再动手写代码。不然写出来的东西全是 bug，调试起来更费时间。
2. **善用串口调试** - 单片机没有屏幕，调试全靠串口打印。把关键变量都打出来，比你猜来猜去效率高多了。
3. **分步调试** - 别把所有功能都写完再调试，一个模块一个模块来，确认每个模块都没问题了再整合。
4. **多逛论坛社区** - 你遇到的 99% 的问题，别人都遇到过。CSDN、GitHub、B站，都是好东西。
5. **做好记录** - 把遇到的问题和解决方法都记下来，不然下次遇到同样的问题还得重新查。我就记了满满一本子的调试笔记，后面真的经常翻。

## 📝 遇到的问题与解决

| 问题 | 原因 | 解决方案 |
|:----:|:----:|----------|
| 电机调速抖动大 | PID 参数不合适，D 项过大 | 重新整定 PID 参数，降低 Kd，增加滤波 |
| 姿态角漂移严重 | 陀螺仪零漂 + 加速度计噪声 | 加入卡尔曼滤波，融合两种传感器数据 |
| 超声波数据跳变 | 环境干扰 + 多次反射 | 加入滑动平均滤波 + 异常值剔除 |
| 循迹误判 | 光线变化影响红外传感器 | 增加传感器阈值自适应校准 |
| 电机启动时单片机复位 | 电机反电动势干扰电源 | 电机单独供电 + 增加滤波电容 + 磁环 |
| MPU6050 I2C 通信卡死 | 上拉电阻不对 + 走线太长 | 更换 4.7K 上拉电阻 + 缩短连线 |
| 超声波测距不稳定 | 温度影响声速 | 加入温度补偿公式修正声速 |

> 更多调试笔记详见 [docs/debug-notes.md](docs/debug-notes.md)
